OLE Packager

Installation
1. Close Microsoft Word.
2. Double-click Install.cmd.
3. Open Microsoft Word.
4. Use the OLE Packager tab, then click Insert OLE Package, Insert Image + Files, or Manage Image/OLE Files.

Uninstall
1. Close Microsoft Word.
2. Double-click Uninstall.cmd.

Notes
- This installer does not require administrator permission.
- It installs only for the current Windows user.
- It installs OLEPackager.dotm and OLEPackagerZipTool.exe into the Word STARTUP folder.
- If installation fails, send install.log to the developer.
